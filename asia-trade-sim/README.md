# アジア貿易シミュレーション

現実の国際貿易フロー（通関書類・NACCS・コンテナヤード・銀行決済）を体験できるブラウザゲームです。

## 拡張貿易フロー（10段階）

```
通関書類作成 → 銀行手続 → NACCS/電子申告 → 輸出通関
  → コンテナヤード(CY) → 積込み → 輸送中
  → 輸入通関 → 関税納付（銀行経由） → 搬出・入庫
```

## 通関書類

| 書類 | 説明 |
|------|------|
| Commercial Invoice | 商業送り状 |
| Packing List | 梱包明細書 |
| Export/Import Declaration | 輸出入申告書（E/D, I/D） |
| 通関委任状 | Customs POA |
| B/L / AWB | 船荷証券 / 航空運送状 |
| D/O | デリバリーオーダー（搬出指示） |
| NACCSマニフェスト | 電子貨物情報 |
| C/O | 原産地証明書（FTA用） |
| L/C書類 | 信用状セット |

## NACCS / 電子通関

| システム | 対象 |
|----------|------|
| **NACCS** | 日本（東京）— 税関・港湾・通関業者・銀行EDI |
| KTNET | 韓国（ソウル） |
| 中国单一窗口 | 中国（上海） |
| TradeNet | シンガポール |

NACCS連携銀行（三菱UFJ・三井住友・みずほ）で手数料割引。

## コンテナヤード（CY）

各港に複数CY（例: 大井CY、洋山深水港、PSA Singapore）。  
**デマレージ/D&D** — 無料保管日数超過で追加費用。

コンテナサイズ: 20'GP / 40'GP / 40'HC

## 取引銀行

三菱UFJ / 三井住友 / みずほ / HSBC / DBS / 中国工商銀行

決済: T/T前払い / T/T後払い / **L/C（信用状）** / **D/P（手形渡し）**
