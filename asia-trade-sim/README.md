# アジア貿易シミュレーション

東アジア・東南アジアの8都市を行き来し、物価差を利用して富を築くブラウザゲームです。

## 遊び方

1. 各都市の市場で商品を**買う**・**売る**
2. 特産品は産地で安く買える — 他都市で高く売ろう
3. **次の日へ進む**で時間が進み、価格が変動
4. 都市間の移動には数日かかる（移動中も日数が進む）
5. **120日以内**に **$100,000** を達成すればクリア

## 起動方法

```bash
# リポジトリルートから
npm run game

# または直接
npx serve asia-trade-sim -p 3000
```

ブラウザで http://localhost:3000 を開いてください。

## 機能

- 9種類の貿易商品
- ランダム市場イベント（台風、祭り、FTA、海賊など）
- セーブ / ロード（localStorage）
- レスポンシブUI
