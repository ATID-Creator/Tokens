# アジア貿易シミュレーション

東アジア・東南アジアの8都市を行き来し、**インコタームズ**と**実際の輸出入費用**を考慮しながら富を築くブラウザゲームです。

## 遊び方

1. **インコタームズ**（EXW / FOB / CIF / DDP）を選択
2. 各都市の市場で商品を買う・売る
3. 他都市へ移動する際、貿易費用の内訳を確認して出航
4. **120日以内**に **$100,000** を達成すればクリア

## インコタームズ（Incoterms 2020 簡略版）

| 条件 | 名称 | あなたの負担 | 特徴 |
|------|------|-------------|------|
| **EXW** | 工場渡し | 運賃・保険・関税・通関すべて | 購入単価最安。費用・リスク最大 |
| **FOB** | 本船渡し | 海上運賃・保険・輸入関税・通関 | 国際貿易の標準的条件 |
| **CIF** | 運賃保険料込み | 輸入関税・通関・港荷役のみ | 目的港まで運賃・保険は売主負担 |
| **DDP** | 関税込持込渡し | 追加費用なし | 購入単価高いが到着後コストゼロ |

## 貿易費用の内訳

出航時に以下の費用が発生します（インコタームズにより負担者が変わる）:

- **海上運賃** — 距離・貨物重量に比例
- **海上保険料** — 商品価値・リスクに応じた率
- **港荷役(THC)** — 積地・揚地それぞれの港手数料
- **輸出通関・書類** — 輸出側の通関費用
- **輸入通関・書類** — 輸入側の通関費用
- **輸入関税** — 各国の関税率 × 品目別係数（FTAで減免あり）
- **VAT/消費税** — (CIF + 関税) × 各国税率

## FTA（自由貿易協定）

以下の地域間では関税率が最大50%減免されます:

- **RCEP**: 日本・中国・韓国・シンガポール・タイ・ベトナム・インドネシア
- **ASEAN**: シンガポール・タイ・ベトナム・インドネシア
- **日韓FTA**: 日本 ↔ 韓国

## 起動方法

```bash
npm run game
```

ブラウザで http://localhost:3000 を開いてください。

## 戦略のヒント

- **EXW** で安く仕入れ、利益幅が大きい路線なら自己負担の運賃・関税を上回れる
- **CIF/DDP** は費用管理が楽だが、購入単価プレミアムが利益を圧迫
- インド（ムンバイ）は関税率18%と高い — FTA対象国からの輸入を優先
- シンガポールは関税0% — 再輸出の拠点として有効
- イベント「FTA発効」「通関遅延」が貿易費用に影響
