# アジア貿易シミュレーション

現実の国際貿易フローを体験できるブラウザゲームです。船会社・航空会社・通関業者・フォワーダー・インコタームズ・貿易書類など、実務に近い要素を再現しています。

## 貿易フロー（6段階）

```
書類作成 → 輸出通関 → 積込み → 輸送中 → 輸入通関 → 搬入完了
```

各 Shipment は日数進行でステージを進み、輸入通関では税関検査・検疫遅延が発生する場合があります。

## 主要機能

### 輸送手段
| 手段 | 特徴 |
|------|------|
| 🚢 海上コンテナ | 大量・低コスト。Maersk, ONE, COSCO, Evergreen, MSC |
| ✈️ 国際航空貨物 | 高速・高コスト。ANA Cargo, SQ Cargo, Cathay, Korean Air, FedEx |
| 🚂 国際鉄道/陸送 | 地域限定（例: 東京↔ソウル、バンコク↔ハノイ） |

### 通関・物流
- **通関業者**: 一般 / AEO認定 / 現地特化（検査率・速度が異なる）
- **フォワーダー**: 直接手配 / DHL / Kuehne+Nagel
- **貿易書類**: Commercial Invoice, Packing List, B/L, AWB, 原産地証明(C/O), 検疫証明
- **決済**: T/T前払い / T/T後払い / L/C（信用状）

### インコタームズ
EXW / FOB / CIF / DDP — 費用負担分界点が異なります。

### 倉庫システム
- 各都市に倉庫。仕入れは現地倉庫へ入庫
- Shipment で他都市へ送る。プレイヤーは「出張」で移動し、現地倉庫の在庫を売却

## 起動

```bash
npm run game
```

http://localhost:3000

## 勝利条件

**150日以内**に総資産（現金＋全倉庫在庫＋輸送中貨物）**$120,000** 達成

## 戦略ヒント

- 航空便は鮮度重要品（海産物）や高単価品（電子部品）向け
- インド（ムンバイ）は検査率が高い — AEOブローカー推奨
- C/O（原産地証明）で FTA 追加減税
- 出張で需要先を確認してから Shipment を手配
