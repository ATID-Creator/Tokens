# アジア貿易・外交シミュレーター

アジア圏と日本の貿易・外交関係を仮想空間上でシミュレーションするWebアプリケーションです。

## 機能

- **インタラクティブ地図**: アジア太平洋地域16カ国を仮想マップ上に表示
- **外交アクション**: 首脳会談、貿易協定、経済援助、制裁措置、文化交流、安全保障協力
- **貿易シミュレーション**: 各国との貿易額・関税率・関係度の動的変化
- **ターン制進行**: 四半期ごとにシミュレーションを進行、ランダムイベント発生
- **リアルタイムダッシュボード**: 予算、外交影響力、GDP、総貿易額を表示

## 起動方法

```bash
cd asia-sim
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開いてください。

## ビルド

```bash
npm run build
npm run preview
```

## 遊び方

1. 地図上の国をクリックして選択
2. 外交アクションを実行（予算と外交影響力が必要）
3. 「四半期を進める」でシミュレーションを進行
4. 各国との関係度と貿易額の変化を確認

## 技術スタック

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
